同步与性能

进度相差多少秒后触发同步；数值越小，同步越紧密

允许应用的最大延迟补偿（100–10000 毫秒，默认 5000）

全局设置

调整参与者的同步位置：正值使参与者略微超前，负值增加延迟（-10000 到 +10000 毫秒，默认 1000）

安全设置

使用 HTTPS 代替 HTTP，需要通过 netsh 绑定证书。
重要：必须先绑定证书，并以管理员身份运行：
netsh http add sslcert ipport=0.0.0.0:8097 certhash=YOUR_CERT_THUMBPRINT appid={00000000-0000-0000-0000-000000000000}
SSL 证书指纹（40 位十六进制），可在 Windows 证书管理器（certmgr.msc）中查找。
防止跨站请求伪造攻击；服务器暴露在互联网时建议启用。
向 HTTP 响应添加安全响应头（X-Frame-Options、CSP、X-Content-Type-Options 等）。
CSP 响应头内容。默认值在允许必要脚本和样式的同时防止 XSS 攻击。
强制浏览器使用 HTTPS；仅在 HTTPS 已启用并正常工作时开启。
浏览器记住使用 HTTPS 的时间（默认 1 年，范围 0–63072000 秒，即 2 年）。
多次登录失败后临时封禁 IP，防止暴力破解。
触发锁定前允许的失败次数（默认 5 次，范围 1–20 次）。
登录失败后的锁定时间（默认 15 分钟，范围 1–1440 分钟）。
统计登录失败次数的时间窗口（默认 10 分钟，范围 1–60 分钟）。
记录登录、创建或删除房间等安全事件，便于监控。
内存中保留的审计日志上限（默认 1000 条，范围 100–10000 条）。
Windows 必需设置：

Windows 必须授权 Web 服务器使用该端口。请在 PowerShell 或命令提示符中以管理员身份运行：

netsh http add urlacl url=http://*:8097/ user="Everyone"

修改端口后，必须用新端口号重新运行该命令；Web 服务器会自动重启。

Linux / Docker 设置：

Linux 上较少出现“访问被拒绝”，但 Emby 运行权限不足时仍可能发生。

Docker 用户：创建容器时必须映射该端口。请在 docker run 命令中添加：

-p 8097:8097

请将端口替换为你选择的端口号。

工作原理

适用于各类 Emby 客户端的一起看房间

1. 管理员选择用于一起看的媒体库
2. 管理员选择内容并创建房间
3. 插件在指定媒体库中自动创建 STRM 文件
4. 用户浏览该媒体库并播放条目，即可加入房间
5. 所有人的播放进度保持同步

使用方法：

  1. 管理员：从“一起看媒体库”下拉框选择目标媒体库
  2. 管理员：在上方选择要观看的内容
  3. 管理员：启用房间并点击“创建一起看房间”
  4. 自动处理：单个条目会创建一个 STRM；整部剧集房间会创建有序的剧集目录
  5. 所有用户：进入该媒体库并播放内容
  6. 同步：插件会保持所有人的进度一致，并自动扫描媒体库

STRM 文件结构：

创建房间时，插件会生成指向所选内容的 STRM 文件。单个条目沿用原始媒体文件名； 整部剧集房间使用独立且不会重名的目录，并按季创建子目录、按集数排列文件。 创建完成后会自动重新扫描所选媒体库。

客户端支持：

  • Emby 网页版
  • Emby Android 客户端
  • Emby iOS 客户端
  • Emby 智能电视客户端
  • 第三方客户端只有实现 Emby 远程播放状态与播放命令后才能可靠同步

同步方式：

房间启用后，插件会监听播放事件。用户播放一起看媒体库中的 STRM 条目时， 会自动跳到房间的当前同步位置。主控用户决定当前集、播放进度、暂停和拖动，其他参与者跟随。

故障排查：

  • 进度不同步？确认已勾选“立即启用房间”并保存
  • 看不到 STRM 文件？在 Emby 中扫描媒体库，或检查 STRM 目录路径
  • 内容选错？删除房间后用正确内容重新创建
  • 需要日志？启用上方“调试日志”并查看服务器日志
